# LeadHunter AI

Plataforma SaaS para descobrir, qualificar e organizar empresas com presença digital limitada ou sem website identificado.

## MVP

- Dashboard comercial com indicadores e pipeline.
- Filtros por cidade, segmento e situação do website.
- Qualificação de oportunidades com evidências e nível de confiança.
- Gestão de leads e geração de abordagens para WhatsApp.
- Exportação CSV.

## Desenvolvimento

O primeiro incremento entrega a interface funcional com dados demonstrativos locais. A descoberta real de empresas exige conectar provedores de dados autorizados e configurar suas credenciais no backend; o sistema não deve declarar ausência de website sem evidência verificável.

## Stack

React, TypeScript, Vite e CSS.
